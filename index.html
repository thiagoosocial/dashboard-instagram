🔑 Integração com API do Instagram

📓 Como obter seu Access Token:

  1. Acesse developers.facebook.com
  2. Crie um app do tipo Business
  3. Adicione o produto Instagram Graph API
  4. Gere um token com permissões: instagram_basic, instagram_manage_insights
  5. Cole o token acima e salve

⚠️ Esta versão armazena o token apenas localmente no seu navegador.

🔁 Sincronizar com Instagram
